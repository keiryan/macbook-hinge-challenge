Welcome to hinge

Your screen, in degrees.

Read your MacBook’s lid angle as you move the screen. For a little challenge, find three random angles from the menu.

For the best experience, open your browser in full screen.

Safari · No direct browser access

Use desktop Chrome or Edge, or keep Safari and run the local native reader.

Open in the browser

Use desktop Chrome or Edge with a compatible MacBook. Choose the lid sensor when asked. No download needed.

Go native for smoother motion

Run the local helper on your Mac. Requires Python 3 and Apple’s Swift compiler. Works with Safari, too.

50×

More frequent readings in native mode on the tested Mac: about 50 reads/sec versus one browser report/sec. Rates vary; this compares read frequency, not measured latency.

Requires a compatible MacBook with a readable lid-angle sensor. Check your model in the compatibility guide below.

Run the native reader locally

The native helper runs on your own Mac. Follow the GitHub setup instructions, then run this from the downloaded project directory:

./scripts/run.sh

Open http://127.0.0.1:8768/, then choose Connect your MacBook → Use native reader. The hosted page cannot run the helper against your hardware.
Under the surface

Every received reading.

Read frequency and hardware update frequency are different. The display does not smooth or invent angles.

Browser arrival and native read-completion times are separate; neither is a hardware capture timestamp. Native reads delayed more than 150 ms are discarded. Native mode requests up to 60 reads/s; repeated values may reflect the same sensor measurement.
