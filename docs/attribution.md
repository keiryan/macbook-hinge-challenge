# Attribution

The experiment was inspired by [this iPhone Duo hinge CAPTCHA demo](https://www.linkedin.com/feed/update/urn:li:activity:7510100128687579136/), which prompted the question of whether a MacBook could support a similar physical interaction.

The following projects informed the sensor discovery and report-format research:

- [TANG617/LidPerspective](https://github.com/TANG617/LidPerspective), including its [WebHID research notes](https://github.com/TANG617/LidPerspective/blob/main/web/README.md).
- [samhenrigold/LidAngleSensor](https://github.com/samhenrigold/LidAngleSensor), a native lid-angle sensor project.

This repository contains the standalone demo implementation and its tests. It does not vendor either project's source, binaries, or assets. Refer to each upstream repository for its own license and authorship information.

Apple, MacBook, macOS, and the browser names identify the hardware and software used. This is an independent experiment, with no claimed endorsement from their owners.
